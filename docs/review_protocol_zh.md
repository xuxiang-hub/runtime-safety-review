# 系统综述公开方法协议

## 1. 研究范围

本综述考察学习型交通系统中从风险或不确定性信号到运行时决策与干预的证据链，重点覆盖：

1. 风险、不确定性、异常或分布偏移如何被定义和估计；
2. 信号是否经过校准，是否具有统计或形式保证；
3. 信号是否被规划、控制或运行时保障模块消费；
4. 风险触发何种干预，以及验证是否形成闭环；
5. 方法是否报告实时性、对其他交通参与者或交通系统的影响。

正式数据库检索覆盖 Web of Science Core Collection、Scopus、IEEE Xplore 和 ACM Digital Library。基础研究可经前后向引文追踪补充。完整概念块、数据库字段翻译和可执行生成器见 `search_strategy.md` 与 `../scripts/generate_database_query.py`。

## 2. 记录规范化与版本归并

原始记录先规范化 DOI、Unicode、题名、作者和年份。去重优先使用规范化 DOI；无 DOI 的记录使用题名、作者和年份的联合证据。会议论文、期刊扩展版和其他公开版本形成关联组，每组保留信息更完整或出版状态更高的首选版本，同时保持原始记录到规范研究标识的映射。

数据库许可不允许公开重分发全部原始导出，因此公开仓库提供计数链、查询逻辑、稳定书目标识、公开字段和验证脚本，不提供受限导出或批量完整摘要。

## 3. 筛选与证据深度分流

题名—摘要筛选采用高召回边界：明确不相关的记录排除，主题相关或仅凭摘要不能稳定裁决的边界记录继续保留。数据库候选和引文追踪候选合并、再次去重与版本归并后，9,001 篇唯一研究均按统一主题范围和纳排边界完成处置。全文通过 DOI 解析、题名—作者匹配、开放获取仓储和项目既有馆藏进行规范化检索，文件通过题名对应关系和文档完整性验证后进入资格判断：

- **全文资格与证据综合路径：** 516 篇成功取得可核查全文并完成资格判断；295 篇进入基线全文综合，221 篇判为邻域排除。另有 8 篇通过其他预定义识别方法发现并按同一标准纳入，最终全文综合为 303 篇。
- **题名—摘要/元数据映射路径：** 8,485 篇仅完成题名、摘要或元数据处置，其中 6,604 篇保留用于宽口径主题与来源映射，1,881 篇排除。

两条路径属于同一筛选流程，并共享主题边界与资格标准。全文获取状态决定可实施的证据深度：摘要级记录用于主题、年份、来源和摘要可见接口的映射，可核查全文则用于机制、保证、干预和验证成熟度编码。最终 9,009 篇唯一研究完成处置，其中 6,907 篇进入宽口径综述语料，2,102 篇排除。完整算术见 `../data/screening_flow.csv`。

## 4. 全文研究的互斥证据角色

| 角色 | 操作定义 | 数量 |
|---|---|---:|
| `core` | 道路交通或自动驾驶场景；含学习型预测、规划、策略或风险监测组件；风险、不确定性或异常信号被下游规划、控制或保障模块实际消费，并改变约束、候选选择或物理动作；同时报告安全或任务层评价 | 61 |
| `contextual` | 对预测—规划风险接口具有直接方法学价值，但至少缺少一个核心闭环环节，例如道路交通验证、明确风险语义、校准证据、规划消费或实际干预 | 242 |
| `excluded-neighbor` | 仅进行上游感知异常/OOD、仅生成测试场景，或仅依赖预设安全约束控制而没有学习型风险到行动接口；保留在筛选边界记录中，不进入证据综合 | 221 |

`contextual`表示证据角色而非质量等级。真实道路数据上的离线感知评价也不会仅因数据来源真实而自动升级为系统级闭环验证。

## 5. 全文编码与边界控制

每篇合格全文研究按固定字段编码书目信息、交通任务、风险来源、偏移构造、信号—风险关系、不确定性输出、校准目标、决策消费、统计保证、形式控制保证、运行时干预、数据集和评价证据。缺失值严格区分“不适用”“已核查但未报告”“仍无法确定”和“明确不存在”。

边界记录接受附加一致性检查；任何分歧都回到操作定义和可定位证据进行裁决。公开表只保留重算主要主张所需的最终字段，不公开全文摘录、页码定位、本地文件路径和非分析性工作流字段。

## 6. 定量综合

研究任务、数据集、风险事件和评价指标高度异质，因此本综述不合并 ADE、coverage、碰撞率或控制性能的跨研究效果量，也不实施可能产生误导的 meta-analysis。主要综合包括：

- G0–G4 统计保证强度分布；
- 与 G 正交的形式控制保证；
- V0–V5 验证成熟度及 G×V 交叉表；
- `core` 与 `contextual` 分层结果；
- 决策消费、闭环、多主体、延迟、交通影响和偏移构造；
- 七项综合发现各自的筛选条件、分子、分母、解释和适用限制。

主题标签允许重叠，因此主题百分比不能相加为 100%。摘要中没有出现某机制也不能解释为全文证明该机制不存在。

## 7. 可审计性边界

公开材料允许审稿人重建筛选计数、连接 303 篇全文编码与 G/V 画像、复算综合发现并核对 Table I 评分。受版权和数据库许可限制，原始数据库导出、批量完整摘要、论文全文和逐页摘录不在仓库中重分发。稳定 DOI、正式链接和参考文献键用于支持合法访问条件下的来源核查。
